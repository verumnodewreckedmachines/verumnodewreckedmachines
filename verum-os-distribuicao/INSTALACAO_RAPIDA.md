# 🚀 INSTALAÇÃO RÁPIDA - VERUM OS

## ⚡ INÍCIO EM 3 PASSOS

### 1️⃣ INSTALAR DEPENDÊNCIAS
```bash
npm install
```

### 2️⃣ CONFIGURAR DATABASE
```bash
# Configure sua DATABASE_URL no ambiente
npm run db:push
```

### 3️⃣ INICIAR SISTEMA
```bash
npm run dev
```

**Pronto! Acesse:** http://localhost:5000
